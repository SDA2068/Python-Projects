# Python-Projects
A collection of Python desktop apps built with tkinter.

## Projects

**Blackjack** — A fully graphical Blackjack game with card visuals, 
win/loss tracking, and casino-style felt table UI.

**Number Guessing Game** — Singleplayer and local multiplayer modes. 
Pick a difficulty, or go head-to-head with a friend and race to guess 
each other's secret number first, based on the viral trend.

**Pomodoro Timer** — A productivity timer with an animated progress ring, 
automatic work/break cycling, and session tracking.

## How to run

Make sure Python is installed, then run any file directly
No installs needed — only uses Python's built-in libraries.
